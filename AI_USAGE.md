# AI Usage

This document explains how AI was used to build the HelpMyCoach landing page, as required by the challenge brief.

## 1. AI tools used

- **Claude (Anthropic)** — via the Lovable agentic coding environment. Used for scaffolding, design-system generation, component code, and copywriting.
- **Built-in image generation** — used to create the cosmic hero background (`src/assets/hero-cosmos.jpg`).

## 2. What AI was used for

- Designing the visual direction and token system (a "cosmic-gold" spiritual palette in `src/styles.css`).
- Generating all section components (Hero, WhoWeHelp, Problem, WhyHelpMyCoach, HowItWorks, Pricing, SocialProof, AuditForm, FAQ, FinalCTA, Footer).
- Writing the marketing copy and the structured content data in `src/lib/site-data.ts`.
- Setting up form validation with `react-hook-form` + `zod` for the audit form.
- Implementing scroll/interaction animations with `motion` (Framer Motion).
- Drafting this `AI_USAGE.md` and the `README.md`.

## 3. Example prompts

1. *"Build a responsive landing page for HelpMyCoach, a digital marketing company for spiritual coaches, healers and astrologers. Use a distinctive cosmic-gold theme, emojis for each niche, scroll animations, an interactive timeline for the process, a billing toggle on pricing, a react-hook-form audit form, and an interactive FAQ accordion."*
2. *"Create a 'How it works' vertical timeline with an animated progress line that fills as the user scrolls, alternating cards left/right, and the 6 steps: Discovery → Strategy → Content → Editing → Publishing → Review."*
3. *"Build a pricing section with a monthly/quarterly toggle. Quarterly should give ~2 months free. Animate the price when the toggle changes, and highlight the 'Grow' plan as most popular."*

## 4. Parts generated by AI

- All React component files under `src/components/site/`.
- The design system in `src/styles.css`.
- The content data file `src/lib/site-data.ts`.
- The route composition in `src/routes/index.tsx`.
- The hero background image.

## 5. Parts I modified myself

- Reviewed and adjusted the design tokens so the gold accent meets WCAG AA contrast against the midnight background.
- Restructured the SocialProof carousel to guard against undefined array access under `noUncheckedIndexedAccess`.
- Tuned the animation timings (stagger, ease curves) so motion improves UX rather than distracting.
- Added semantic labels, `aria-expanded` on the FAQ, and `role="switch"` on the billing toggle for accessibility.
- Verified the audit form's Zod schema handles the `@` prefix on the Instagram field.

## 6. An AI-generated solution I rejected or changed

**Rejected: using `Math.random()` to place the hero starfield.**
The initial approach scattered stars with random top/left values inside the component. This caused a hydration mismatch: the server rendered one set of positions and the client rendered another, leaving visible flicker. I replaced it with a deterministic position array derived from the star index (`(i * 53) % 100`), so server and client always agree and the animation stays smooth.
